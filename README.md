# ChronoTrigger reMaster — HD-2D prototype

Private development repository for a browser-first, local-cooperative HD-2D RPG prototype.

## Project decisions

- Priority: the shortest path to a genuinely playable prototype, not a full remake claim.
- Stack: TypeScript + Babylon.js, browser first. Desktop/mobile packaging is deferred.
- Cooperation: two players on one device first; separate input ownership and a shared camera.
- Preserve ATB-style command combat initially; real-time action combat is a separate design decision.
- Prototype graphics and dialogue are independently authored placeholders, not final Chrono Trigger assets.
- No ROM, extracted original assets, original soundtrack, credentials, or user uploads are committed.
- No public deployment or repository visibility change is authorized by this setup.

The first implementation is being assembled and locally validated. This initial commit only establishes the repository; it is not a playable release.
