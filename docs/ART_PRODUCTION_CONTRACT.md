# 可進引擎的美術製作契約 — r1 / 0.8 batch

這是既有 QUALITY_AND_ASSETS、reference index 與 PNG/JSON 匯出流程的具體化，不是另一套素材系統，不是全遊戲美術核准書。**先定尺度、分層、材質與交付格式，再按可玩章節做素材並在引擎驗收；不等待全遊戲素材一次做完。**

## 原汁原味與優化的界線

保留原作的場景辨識、縮尺大地圖和 Field/室內分工、入口與出口的語意、人物輪廓、原地 ATB 和鏡頭閱讀方向。HD-2D 的光影、幾何厚度、材質層次只能增加可讀性，不拿寫實貼圖、自由旋轉、重度景深或全新 ARPG 取代原作。地圖鄰接、劇情條件、房間拓樸、動作時序與美術是一組對照工作，單張漂亮圖不代表忠實還原。

現有原圖對照登錄在 assets/reference-index.json；研究與未核對項目在 ORIGINAL_FIDELITY.md。使用者提供的繁中 Beta ROM 已私人留存、完整雜湊回讀相符；本批沒有執行、解碼或擷取它，不能據此宣稱已逆向原版。

本次另外取得 SNESMaps 的監獄地圖頁與地圖目錄文字，但原圖 URL 在工具中回傳 cache miss／下載失敗；因此**沒有新增「已目視該原圖」的證據**，也不把目錄圖幅尺寸當成遊戲原生解析度。新材質是依既有對照紀錄和 CI13 實際畫面缺口作手工增量，不是原始圖片拷貝。

## 唯一可執行規格

`src/art-profile.ts` 是本批程式契約；匯出時產生 `dist/art/production-profile.json`。資料被 renderer、碰撞、PNG exporter 與測試共同使用，不只寫在本文件。

| 層級 | 本批契約與驗收方式 |
|---|---|
| 角色 | 沿用 24×32 cell、腳底 pivot(12,31)、四方向與既有戰鬥姿勢。這是專案慣例，不冒稱原 ROM atlas 規格。PNG 透明邊界、nearest sampling、幀尺寸與腳底需一致。 |
| 縮尺大地圖 | 角色比例0.4；orthographic 最小半高9、半寬12，保留地名與確認入場。房屋、樹與山是地圖符號，不是把室內實尺物件搬上大地圖。完整原作海岸線與世界鄰接尚未完成。 |
| 家中室內 | 半高5.5、半寬7；暖木、灰泥、象牙布料，低近牆／北牆剖視。保留房間和一樓換圖、床鋪／窗戶辨識。窗簾摺線跟著窗簾移動，不留在原地。 |
| 原野／法庭／牢房 | 半高6.2、半寬8；維持同一讀圖方向，法庭以彩窗、台階、陪審座位分層，牢房以冷石牆、鐵欄和木製床具區分。戰鬥不換成無關背景。 |
| 建築材質 | 木、灰泥、瓦頂、石材、鐵件共五個64×64手繪 pixel 材質。每2個世界單位重複一次，以各面實際尺寸計算UV，不把一張石磚拉伸整面牆。每場景快取，不在 render loop 重建材質。 |
| 吊橋 | 場景16×14，橋面半深1.8、角色邊界預留0.25，維持碰撞中心限制±1.55。底圖橋面像素由同一數據計算；欄杆±1.75。不可畫出看似可走卻被隱形邊界擋住的寬橋面。 |
| 龍戰車 | 頭、車體、輪分開資產與真實敵方部位；兩幀表現使用 simulation ticks，每18 ticks換幀，背包／背景暫停不繼續轉動。動畫仍是專案自製，不是原作精確幀序。 |

本批沒有改全域操作、碰撞框架、ATB或角色權限。沒有把這些美術常數寫進存檔，v1–v7 的相容性由既有規則驗證。

## 真正交付的資產

沿用 `npm run assets:export`，本批輸出 **42 組 PNG/JSON、421 筆幀記錄**，另含 production-profile.json、asset-report.json、來源路徑與來源 SHA256。五材質、山形圖示和龍戰車兩幀與引擎使用相同繪製函式，不是只有一份概念海報。原 PNG／ROM／音樂未打包。

PNG 可以交付作檢查與後續編修；**外部修改 PNG 的執行期回匯尚未完成**。現在引擎使用對應手繪函式生成 DynamicTexture，不可以將這套流程描述成已完成任意 atlas/glTF 匯入。UI、肖像、全人物、更細動作、全 OST、材質美術審核均仍有缺口。

## 本批證據與未通過的門檻

375 項本機測試通過，包含幀差異、透明邊、整數像素重複輸出、五種材質、五種螢幕比例、碰撞／橋面對齊、室內戰鬥指令不被家屋樣式隱藏及程式確實使用規格。TypeScript、資產檢查、build、42組資產匯出成功。

新的 browser journey 檢查實際龍戰車動畫幀切換、背包暫停凍結和直向UI，並保存法庭／牢房／吊橋等真實截圖。本機再次嘗試瀏覽器導航時，環境回傳 ERR_BLOCKED_BY_ADMINISTRATOR，未繞過；**新引擎畫面尚待本批CI，不把純函式測試當成視覺通過。**

CI13已通過的家中、大地圖、初遇、600年與亞克拉提示畫面仍是前版證據，不可冒充本批新材質截圖。所有新資產維持 review-not-approved。90分與全遊戲驗收仍未通過；必須保留拓樸、原作陪審規則、音樂與真機等缺口。
