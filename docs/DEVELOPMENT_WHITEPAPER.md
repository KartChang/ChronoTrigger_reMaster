# ChronoTrigger reMaster 開發白皮書

版本：handoff-2026-09-18。這是對既有架構與已授權目標的歸納，不重訂產品、不更換引擎。動態 source／CI 以 STATUS.md 為唯一準據；切片細节沿用 FAIR_SLICE、OPENING_SLICE、KINGDOM_SLICE、RESCUE_SLICE。

## 目標及固定決策

以原版圖像與行為參考製作具辨識度的 HD-2D 重製，讓使用者優先取得可玩的瀏覽器版本。2D 像素角色＋3D 場景、固定俯斜視角、ATB。先單人及同機雙人共用畫面；類似聖劍傳說的合作訴求不代表改成即時ARPG。玩家端不需會員、後端、Python、PHP或ROM。

主要語言 TypeScript；呈現 Babylon.js；esbuild 自含HTML。Node.js是工具鏈，Python/Playwright是驗收。不得為其他專案習慣引入.NET/SQL/RAG/SaaS基礎建設。本案不是GauAI或IoT Colony。

## 既有系統，不重新建造

輸入由 Controls 形成指令與向量，main管理生命週期與固定步長，core執行規則，render與HUD呈現。ATB、傷害、資源與事件不由畫面決定。固定1/60秒步長；暫停、背景、對話不推進，恢復不補算全部背景時間。

P1/P2擁有獨立移動、目標和指令；合技雙方確認後原子消耗。InputBoundary處理場景／劇情切換，避免吞長按；A*利用共同碰撞資料，不穿牆／瞬移。第三有效同伴有自己的HP/MP/ATB、AI與敵人目標性；尚不等於完整自由換人／技能管理。

IndexedDB保存本機進度，JSON白名單還原且保留大小、型別、位置、前置旗標與版本檢查。v1原創村落、v2千年祭、v3異變／山道、v4王國、v5救援；舊進度不因新章節重置。狀態快照／paused／view僅觀察，不以測試hook直接完成劇情。

## 現有內容邊界

現有路線涵蓋千年祭已有同行、傳送異變、600年山道、托魯斯、森林、王城、露卡加入與修道院救援返鄉。0.6源碼已提交，最後一段實際瀏覽器验收未結束。三房間救援是壓縮重建，不能宣稱原版全部迷宮、數值與演出已還原。

真正的初始開場、審判／越獄、完整物品裝備商店成長、其他角色技能、剩餘時代支線結局和音樂仍未完成。完整目標不縮小，但不因此重新實作已存在框架。後續按TODO增量做可玩的連貫切片。

## 美術與原版參考

參考來源及平台不確定性記assets/reference-index.json。角色與場景手製繪製函式可匯出PNG/JSON，保留腳底pivot、方向、timing與動作名稱；目前26張PNG、402筆影格紀錄不是402張獨特原作動畫。素材manifest區分missing/prototype/review/approved。

生成概念圖只是期望方向，不是原版設定或引擎成果。每批以原版實際圖片校準，再在遊戲中看比例、遮擋、角色動作、技能節奏與場景可讀性。先做足夠支撐一個切片的可重用素材，不等待全遊戲資產完成。外部PNG回匯、完整glTF內容工具、音樂與完整場景模型源檔流程仍不能算已完成。

本輪沒有讀取、擷取或公開保存使用者ROM。未確認版本、工具相容與用途之前，不承諾整包ROM自動轉HD-2D；原作圖片／音訊不混入公開repo或交付包。公開發行清權與參考可取得性分開記錄。

## 驗收與交付

每批執行與風險相稱的單元／型別／建置、真實按鍵UI的browser journey與畫面檢查。已提交≠CI通過≠已部署≠美術合格≠完整遊戲。舊30/100已stale，不是現版新評估；總分>=90、各面向>=80%、critical gaps為零且證據／必需素材通過才可release:check。

品質門檻不允許靠刪欄位或缩小到單一demo提高分數，也不要求在劇情未實作時停止開發等待90分；按切片修正、保存缺口並繼續補齊整體。

GitHub Pages展示已通過CI的exact artifact，保存來源與HTML hash，不另建置未驗證內容。線上原則上維持上一成功版本直到新驗收與部署成功。file://與網站存檔不自動共用，使用JSON搬移；不宣稱有雲端同步。

## 雲端保存與工作治理

GitHub main保存source與權威進度，Drive專案folder保存候選、已驗收包、素材和證據；每次交付附收據及SHA256。使用者確認repo只有此AI操作：不開多人協作防撞工程、不建立平行候選、不中斷去審全部歷史。只作一次最新HEAD/run sanity check，然後接TODO。

STATUS記exact執行點；TODO提供任務與完成條件；FEATURE_PROGRESS保留checkpoint快照；本白皮書維持穩定設計。新對話先讀handoff及STATUS，不重新讀全部白皮書、舊分支或所有artifacts。臨時容器不是記憶，重新開環境可從GitHub和Drive恢復，但不得從舊ZIP覆蓋較新main。
