# T04 第一批：角色狀態、裝備、旅費與交易（0.9.0）

2026-09-18。延伸既有 core／背包／IndexedDB／JSON 保存，不建立第二套遊戲框架。這是本批已實作、待新 CI 瀏覽器驗收的功能；不是 T04 全部完成，也不是原作數值核准。

## 玩家操作與實際效果

在探索中按 I，或使用既有背包按鈕，檢視目前劇情隊伍的 HP／MP、武器／身體／頭部裝備及傷害加成。可以切換正在場的角色頁，但不能藉此召回離隊角色、更換劇情隊伍或增加 P3。克羅諾、瑪兒、露卡與青蛙各自保有裝備；第三同伴仍是自主角色。戰鬥中能看狀態，不能換裝或交易。

新遊戲與舊存檔在尚未使用本功能時，顯示預設裝備及本批暫定旅費400G。只有成功交易或換裝才產生持久裝備狀態；只打開選單不改寫存檔版本。這筆初始旅費是明示的重建／舊檔移轉政策，不是聲稱從舊紀錄推算出來的戰鬥收入；本批尚未加入戰鬥金幣獎勵。

千年祭南側接近現有梅爾基歐 NPC 後，畫面提示 I 裝備買賣。攤位頁可買入與售出閒置裝備，金幣／數量同步變動，價格不足、滿額、無庫存或穿戴中的物品無法交易。售價是標價的一半；重複買賣不會賺錢。基本裝備不可售出，所有四位角色已穿戴的副本都被保留，不能賣掉離隊角色身上的裝備。商店不會改寫項鍊買賣、午餐、尋貓或審判證詞。

武器加成實際進入普通攻擊；身體與頭部防禦實際減少敵方傷害，最低1。角色普通攻擊基礎、原有技能48／3MP、雙確認合技4MP、龍戰車頭部火焰防護、敵人與劇情進度均沿用既有規則。自主青蛙／瑪兒也使用自己的裝備加成，不借用人類控制槽。

## 暫定資料，不冒充原作表格

13件登錄裝備：四名角色的基本武器、布衣／布帽，與青銅刀、鐵刀、鐵弓、針刺槍、鋼劍、青銅甲、青銅盔。購買價分別為150／350／150／150／150／120／80G；武器普通攻擊加成6，鐵刀12；青銅甲減傷3、青銅盔2。這些是明示的本批重建值，沒有以私人 ROM 的標頭檢查冒稱已取得原作武器／傷害／價格資料。

目前沒有飾品、消耗品商店、完整全時代商店、經驗升級、角色成長、自由隊伍、技能學習或完整雙／三人技。既有刑務所經驗欄仍只是紀錄，不因新增裝備畫面就變成成長系統。道具操作保留已驗收的章節規則，沒有偷偷改動舊事件資源。

## 保存與邊界

v8 的 schema 為 equipment-v1，保存原本 v1–v7 冒險字串及白名單裝備狀態。v7 內原本的返鄉歷史仍是 v5／v6，不包進另一個 v8；外層禁止遞迴 v8。匯入逐項檢查裝備相容角色／部位、庫存與已穿戴副本、整數範圍、購買／售出紀錄和金幣守恆，不還原 ATB／特效／執行中選單。金幣帳本是資料一致性檢查，不是反作弊或可驗證的真實歷史。

七份既有 CI18 玩家實際匯出檔（v1–v7）以原始 bytes 和來源 manifest 保留，僅供 parser／單元測試。新瀏覽器流程不使用這些固定檔灌進度，而是接同 run 的 prologue-companions-v6.json，再用實際 Tab／Enter／I、原生檔案選擇與自己匯出的 v8 完成驗收。
