# 祭典經歷與法庭證詞 — 0.8.1 候選

本批接 CI14 已驗收的 0.8.0，不重做起床、600年、修道院、越獄、ATB、背包或角色框架。原版參考不是單靠增加像素；本批把祭典互動實際連到後續證詞、裁決與牢房道具。新程式仍待同源瀏覽器驗收，不是完整遊戲或90分通過。

## 可玩的行為與持久化

新遊戲的 conduct 記錄跟著 v6；先關心瑪兒／先取項鍊沿用原旗標。新增真實尋貓（使用既有A*跟隨，不瞬移到主人）、午餐一次性回復、梅爾基歐的項鍊詢問與同意／拒絕、買糖等候／催促、曾拒還項鍊。等候使用模擬時間，暫停／對話不計時，未結束不能存檔。買糖期間 P2 不會把正在挑選的瑪兒移走；P1 仍可選擇耐心等候或離開。

這些事件不是隱藏 debug 指令，不靠改存檔開啟。在傳送異變開始時封存，穿越、王后救援、回到1000年後不能改寫當時經歷。沒有追蹤欄位的舊 v1–v7 存檔保持未知，不能因升級就被補成無罪或有罪。新 v7 的原始 history 仍是玩家真實 v6 保存內容，hearing.rules 固定為 fair-witness-v1；舊 v7 維持舊裁決，不能默默套新算法。

## 原版資料與明確界線

本批讀取原版對話轉錄，核對碰撞問題、找回貓的小女孩、午餐相關質問、兩次財富問題、反駁證詞、兩種刑期說明與牢房包裹。來源：
- https://cot.drackir.com/script5.htm （Trial原遊戲對話／場景轉錄）
- https://gamefaqs.gamespot.com/snes/563538-chrono-trigger/faqs/31563 （Script Perfection Project，Zeality等人的SNES劇本文本）

實作順序：碰撞回答→已找回貓的小女孩→有吃午餐才詢問並呈現相關證詞→財富問題／否認後再確認→兩次否認時才引出項鍊和催促買糖的反駁→裁決。沒有找回貓，不會憑空生成小女孩控訴的台詞。新對話是短篇自製轉述，不打包原版文字或影像資料。

**仍不是原 ROM 的七名陪審員隱藏程式。** 現在有可追溯、版本化的七票重建規則：項鍊處置、貓、催促買糖、拾取先後／財富、財富答覆、午餐、碰撞／午餐答覆。未接觸尋貓保留未知；成功送回貓會覆蓋先前求助狀態，不模仿部分版本被回報的隨機／殘留旗標行為。此處是公開寫明的確定性改編，沒有宣稱逆向驗證。原始版差、陪審隱藏邏輯及動畫／回憶演出還待核對。

無罪後支持者包裹的本批規則：4／5票無罪給1份乙太，6／7票給3份。採用明确標為Super NES的實玩記錄：https://princewatercress.blogspot.com/2024/09/princewatercress-plays-chrono-trigger_0325857664.html 。部分跨版本攻略另列1／2／3／6份（https://gamefaqs.gamespot.com/snes/563538-chrono-trigger/faqs/64344），資料有版差／矛盾，本批選用SNES實玩作者回報的規則；不能由劇本文字推導，也未從使用者繁中Beta ROM驗證。有罪沒有包裹。取得量、領取旗標、已消耗量與看守室原有兩份乙太一起驗證；不能重复領取、用滿魔目標消耗或藉存讀檔超領。戰鬥道具仍按既有ATB規則。

## 新資產與實際畫面問題

新增八名原生48×64配角（小女孩、老人、商人、買糖目擊者、法官、辯護者、大臣、衛兵）與32×32貓／午餐／包裹。它們使用新的整數像素繪製函式，並非將24×32舊圖放大。八名配角目前只有朝前的靜態姿勢，不冒稱已完成四方向動畫；貓有兩幀尾部動作。角色來源仍是自製重建，不是原版擷取或影像生成模型輸出。

同一個 painter 用於動態貼圖與 PNG/JSON。法庭、刑務所及本批祭典人物使用新材質；全世界其他NPC尚未全部換新。CI14實際畫面的彩窗上緣裁切已針對法庭鏡頭與窗幅修正，不放寬碰撞或更換遊戲玩法。readonly inspect 回報實際貼圖尺寸和投影邊界，瀏覽器驗證不能只讀常數代替真實貼圖。
